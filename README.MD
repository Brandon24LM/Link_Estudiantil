# Link Estudiantil

## Descripción
Esta aplicación es una plataforma de tutorías diseñada para conectar estudiantes que necesitan reforzar sus conocimientos con profesores y tutores verificados. Los usuarios pueden encontrar ayuda en distintas materias, reservar sesiones de tutoría y acceder a clases impartidas por expertos. Por su parte, los tutores pueden publicar sus cursos, establecer horarios de disponibilidad y compartir su experiencia, creando una comunidad de aprendizaje colaborativa, segura y accesible para todos.
